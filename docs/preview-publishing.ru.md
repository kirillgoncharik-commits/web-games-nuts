# Превью Nuts Games на основном домене

Целевой раздел: https://nuts.bid/games/. Предлагаемый первый путь: https://nuts.bid/games/cinder-shift/.

## Два репозитория

Игровые исходники и GDD находятся в `kirillgoncharik-commits/web-games-nuts`. Основной сайт собирается из `kirillgoncharik-commits/nutsbid`, ветка `main`, Cloudflare Pages проект `nuts-games`. Его сборка копирует `public/` в `dist/` и формирует страницы сайта. Новый игровой репозиторий автоматически под этот домен не подключён.

## Предпочтительный первый маршрут

1. Создать и проверить статический игровой артефакт с относительными путями для вложенного каталога.
2. Зафиксировать `game_id`, `build_id` и commit SHA игрового репозитория.
3. Перенести подготовленные файлы в `nutsbid/public/games/cinder-shift/`, сохранив отдельную страницу каталога в `public/games/index.html`.
4. Проверить сборку сайта, его CSP, звуковой запуск, согласие на аналитику и неизменность формы связи.
5. Передать изменение в основной репозиторий и дождаться результата Cloudflare Pages.
6. Проверить конечный URL и сохранить предыдущий рабочий артефакт для отката.

На старте перенос артефактов может быть ручным. Автоматизацию между репозиториями добавляем после первого успешного выпуска. Публичная ветка не должна скачиваться без закреплённого SHA во время каждой сборки основного сайта.

## Аналитика и CSP

В основном сайте уже задан GA4 поток `G-HETCM80ZLX` и разрешение загрузки GA после согласия. Игровой адаптер должен использовать тот же выбор пользователя и отправлять явные игровые события. На собственном домене ресурсы Phaser и игры желательно включать в артефакт локально: текущая CSP ограничивает сторонние скрипты и подключения.

Портальные сборки самостоятельны и используют только нужный SDK. Ограничение основного сайта `frame-ancestors 'none'` нельзя механически переносить в пакет для чужого iframe.

## Стадии страницы

Каталог может показывать концепты с ясным статусом. Кнопка игры появляется после проверенного билда. R01 проходит стадии: технический экран, управление, первая миссия, вертикальная сессия, полная кампания. Рабочее название и выбранный сеттинг фиксируем перед публичным маркетинговым оформлением.

Этот файл описывает маршрут публикации. На момент его создания раздел и игровая сборка ещё не опубликованы.
