# Cinder Shift 64 · задание по боевому дизайну кампаний

Игрок, освоивший «Шлюз» Кальдеры, должен узнавать логику боя в следующих двух кампаниях и применять её в более тесных условиях. В комнате B «Шлюза» наземная цель открывает бой, затем вступает дрон. В M1C игрок разбирается с охранником до активной фазы турели. В финальной C укрытия позволяют дробить группу. Эту последовательность переносим на перенос груза в C02 и переключение цепей в C03.

## Постановка по секторам

Числа показывают фактическую расстановку противников в комнатах A, B, C и D по порядку. Лазеры, пар, электрические поля и фазовые столкновения учитываются отдельно. У агрессивного наземного патруля ограничен участок преследования. Резерв начинает атаковать после гибели указанного ведущего и предупреждает игрока перед первым залпом.

| Сектор | A / B / C / D | Что делает игрок |
|---|---|---|
| SW01 · Кухонный каньон | 1 / 2 / 2 / 2 | В A осваивает крышку до патруля. В B занимает низкую ступень перед паром, снимает охранника и сканер по очереди. В D выбирает момент для броска между сканами. |
| SW02 · Настольная орбита | 2 / 2 / 1 / 2 | На клавиатуре освобождает дальний край. В B со ступени выходит на полку с запчастями, пока дрон сменяет наземного робота. В D охранник прикрывает турель. |
| SW03 · Большая стирка | 2 / 2 / 0 / 3 | В B может вести бой с верхней полки или пройти внизу после сканера. В C успевает отремонтироваться. В D три наземные и воздушные цели вступают последовательно у заслонки. |
| SW04 · Балконный ветер | 2 / 2 / 1 / 2 | В A выбирает между низом с наземным роботом и верхней полкой рядом с дроном и тайником. В D совмещает перенос крышки с боем на двух направлениях. |
| SW05 · Вершина роутера | 2 / 2 / 2 / 2 | Низкая книга в A даёт первый подъём к тайнику. В C игрок освобождает линию контактов. В D после турели остаётся ротор и три фазы маяка. |
| YU01 · Дом связи | 2 / 1 / 2 / 3 | После первого наземного патруля вступает орб. Верхняя полка оставляет открытым возврат к рубильнику. В D игрок меняет цепь под двойным огнём, затем встречает резерв. |

| YU04 · Заводской гул | 2 / 2 / 2 / 3 | Верхняя площадка в A позволяет сменить линию огня над конвейером. В D игрок использует фазовые двери как укрытия от турели и выбирает момент для следующего контакта. |
| YU05 · Радио над заливом | 3 / 2 / 2 / 3 | В A на подъёме действуют патруль и орб, после патруля вступает резерв. В C зачистка предшествует работе у антенны. В D орб прикрывает турель, а после орба включается преследователь. |

В C02 размещены 36 роботов в 19 боевых комнатах из 20. В C03 размещены 43 робота в 20 из 20. Базовый состав фиксирован для трёх режимов. У Миры без защитных модулей 6, 5 и 4 HP соответственно. Обычный выстрел снимает 1, 2 и 2 HP, тяжёлый — 1, 2 и 3 HP. Частота атак и дальность активации растут с выбранной сложностью. Контакт снимает 1 HP.

## Цикл приёмки

1. Собрать кандидат и сыграть C01, C02, C03 на простом, сложном и Nightmare. Для сравнения использовать seed 4, штатный ствол и одинаковые настройки помощи. Для открытия C02 и C03 допустимо подставить завершение C01, в результате прогона указать этот факт. Каждый сектор пройти обычным вводом.
2. Для каждой комнаты записать посещение, время под огнём, число предупреждений и попаданий, потерю HP, смерти, повторы и заработанные очки. Отдельно отметить безопасный старт, место для ответа штатным стволом, подход к контакту, доступ к ремонту и выход. Проверять оставшихся роботов, включая резерв.
3. Если сложность падает, определить конкретную причину по записи. Проверить, например, видит ли дрон игрока с основной линии и можно ли уничтожить обе цели с порога. Если проход останавливается, повторить участок без обвеса. Различать тупик геометрии, смерть и ошибку автоматического управления.
4. После правки повторить проблемную комнату, сектор целиком, затем маршрут кампании. Принимать рост давления по атакующим группам, времени под огнём, ошибкам и необходимости сменить позицию. Число смертей одного игрока само по себе этого не доказывает.
5. Принять сборку после девяти полных маршрутов, сохранения финалов и проверки [очков и обвесов](campaign-arcade-score.ru.md). Сохранить версию и результаты каждого прогона. Матрица запускается в рабочем PR и разделена по кампании и режиму.

Исходные данные для воспроизведения находятся в [геометрии и расстановке](../../games/cinder-shift/src/world-rooms.ts), [реестре 40 комнат](../../games/cinder-shift/content/new-campaigns/rooms_40.csv) и [браузерных маршрутах](../../tests/final-world-routes.spec.ts).
