# M03 visual target generation

This is an original concept mockup for art direction. It is not a production atlas, a level map, or authoritative HUD content. Created using the built-in image generation tool. The actual art brief specifies exact gameplay/UI requirements and preserves the existing animation contract.

## Prompt

Use case: ui-mockup / stylized-concept. Create ONE polished art-direction target image for the original browser game CINDER SHIFT, landscape 16:9. This is a visual proposal, not a finished production sprite sheet. Strong inspiration from the readable side-view architecture, chunky armored protagonist, colorful alien industrial silhouettes and distinct screen-sized compositions of the 1987 ZX Spectrum game Exolon; do not reproduce any of that game's actual character, maps, sprites, logos or interface. Contemporary restrained pixel art, intentional sharp pixel clusters, 640x360 logical visual language shown at large integer scale, flat orthographic side-on playable view, no perspective camera, no painterly blur, no 3D rendering. Setting: CALDERA 7, a retrofuturist volcanic-moon geothermal refinery being shut down during the last worker's shift. The service corridor opens through monumental angular windows onto indigo basalt towers, a pale lavender planet, distant muted terracotta ash clouds and an immense turbine. Keep the background dark and low contrast, clear empty air around gameplay. Foreground is precisely readable petroleum-blue modular metal platforms with pale top edge, a short jump ledge, a low crawl tunnel, a power terminal and a tall right-hand exit hatch. Hero Mira is a small heavy industrial rescue engineer in ivory ceramic armor, burnt orange panels, bulky backpack, turquoise slit visor, carrying a practical cutter pointing right; only about 45 logical pixels high and fully readable. One squat four-legged maintenance walker with a coral warning light and one compact triangular maintenance drone, distinct silhouettes, both smaller than the hero. Palette: deep basalt #111823, petroleum #213747, violet shadow #494163, muted blue metal #456171, ivory #F1D8AE, warm ochre #DFA15C, cool mint #76DCC8, amber #FFB65B, danger coral #F36D76. Dominant dark cool environment, hero ivory warm, gameplay accents sparse. Single direction of restrained upper-left lighting, 3 or 4 tones per material, no gradients. Modern clean minimal integrated HUD in a thin top bar: six armor segments left, current objective in center, a simple pause icon at right; small crisp readable sans-serif typography, no retro illegible tiny font. Caption CINDER SHIFT in a modest top-left label. No giant title blocking game, no fake control panels, no excessive chrome, no decorative foreground occlusion, no fog over platforms, no bloom, no lens flare, no smooth animation trails, no tutorial arrows, no bottom HUD. Compose as an attractive credible screenshot from a finished indie game, with the hero occupying the left quarter and the terminal and exit on the right. Image only, no surrounding presentation board, no watermark.
