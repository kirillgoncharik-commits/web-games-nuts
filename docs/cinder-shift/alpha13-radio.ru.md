# Alpha.13 — радио над заливом

20 ноября 2026. Игровой блок 03 из продуктового ТЗ, после отдельного [PR #13](https://github.com/kirillgoncharik-commits/web-games-nuts/pull/13) с диагностикой 01–02. Реализация в локальном коммите `d483b05`; следующий `5dda94f` меняет только версию C01-реестра.

| Комната | Реализация |
|---|---|
| YU05-A | Видимая карта цели над заливом, освещаемая линия B, четыре знакомых уступа и необязательный ресурс наверху. Вход не запускает катсцену. |
| YU05-B | Нижний путь через импульс и верхний мост B. Три рубильника доступны с обеих сторон; возврат A и второй контакт прекращают импульс. Сохранён штатный дрон. |
| YU05-C | Три контакта B/A/B со старыми ID `antenna:phase-0..2`, физическая карта связей. Только подтверждённый префикс записывается в сейв этой кампании. При Retry/Continue восстанавливаются связи и их контур; положение и часы Миры не восстанавливаются в опасности. Новый Replay создаёт новый campaign ID без связей. |
| YU05-D | Первый контакт настраивает B и запускает полное предупреждение 1800 мс. Под навесом x304…392 есть реальное укрытие. Второй контакт доступен только в безопасное окно, снимает физический экран; последний B прекращает импульс и открывает финал. Сохранены итог, история мира и существующий сюжетный переход возвращения Миры. |

## Сохранения и откат

Поле `radio_links` добавлено к существующей кампании C03, без смены ключа или оболочки `schema_version=1 / worlds-rw3.1`. Валидатор принимает только последовательный префикс трёх известных контактов и только после завершённой YU04. Старые профили без поля остаются валидны. Неизвестные/повреждённые данные не заменяются пустой историей. Прежняя alpha.12 игнорирует дополнительное поле; отдельная проверка фактического отката на каждом хосте остаётся в матрице 08.
