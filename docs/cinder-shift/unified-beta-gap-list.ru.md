## Локальная кампания M05B.2–M05B.3

В Литейной терминал открывает обязательный выбор одной ветки, которые сходятся перед R03. Прессовая ветка может включить E04. Архивный транзит закрыт до загрузки данных; E05 предлагает разведку или лечение. В Реакторе есть пять комнат, безопасный участок с R05, добровольная E06 с тараном, бой с Регулятором в два ритма и эвакуация. Все двенадцать исследовательских узлов доступны, включая заряд W4, проход M4 через фазовую завесу и разовое спасение D4. Повтор кампании создаёт новый ID и seed; сводка рекорда хранится отдельно от текущего сохранения.

Это описание реализованного исходника и опубликованного раннего превью, а не доказательство приёмки. `npm run check` подтверждает локализацию и типы, а live label подтверждает версию; они не доказывают геометрию, боевую проходимость, сохранения или баланс. Game acceptance остаётся 0/39.

## Немедленный quality gate по QA-01…QA-12

Текущая следующая работа — принять Airlock и Cargo поверх неизменённого production-превью. Реализация уже включает автоматический расчёт боковой/нижней мобильной компоновки с CSS-pixel кнопками и safe area; короткий HUD и паузу; E01 версии 2 в F с миграцией старого entry; постоянно активную учебную турель E; R02 после ячейки; локальные щиты R01/R02 без остановки боя всей комнаты; staged угрозы в B/C/G; единый селектор состояния/уязвимости турели; обратную связь потери HP и критического состояния; одноразовый загрузочный интро-гейт не менее 6 секунд видимого времени.

Реализация прошла статическую сборку (`npm run i18n:export`, `npm run build`). Это не закрывает QA-приёмку. Нужны игровые сценарии по сохранениям/входам/возвратам, матрица всех заявленных размеров и safe-area fixtures, проверка контакта кнопок, физические устройства, аудио на слух и визуальный контактный лист. В том числе все LOAD-01…LOAD-07 остаются `NOT RUN`; фактические timing evidence не собраны. Не запускать E01 для смены только потому, что игрок вошёл в F: питание включается явным взаимодействием у терминала.
