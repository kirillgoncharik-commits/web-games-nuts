Единый атлас содержит **176 кадров**, 581 KiB после стандартного пиксельного экспорта. Мастера imagegen сохранены без изменения в `art/world-production/source`, точные crop bounds и SHA-256 — в manifest. SVG материалов и рук редактируются по именованным слоям. Экспорт воспроизводится `npm run art:production`; проверка — `npm run art:check`.

В render остаются осмысленные сигналы выстрела, провода, рамка окна и HP босса. Технические hitboxes включаются только отдельной настройкой debug. Их отсутствие в обычном кадре и читаемость реальных атак должны быть подтверждены визуальным прогоном, а не только поиском строк в исходниках.

## Проверки и ограничения

- TypeScript и 964 EN/RU ключа: PASS.
- Контракты прежнего арта и нового атласа: PASS; старые семейства ходока/тарана явно связаны с новыми заменами, исходные файлы и проверки не удалены.
- 72 модели: PASS, включая шесть новых семейств, предупреждение/реальные выстрелы/восстановление/повторный вход, турели Cargo E/F, механизмы миров, радио и старые профили рекордов.
- Сборка: PASS. Браузер локально завершается при запуске Chrome с SIGABRT/EPERM; это **не игровой FAIL и не визуальный PASS**.
- Подготовлен отдельный CI для 44 комнат C01, 20 C02, 20 C03, шести семейств и открытого ядра босса. В нём проверяются отсутствие пропавших ассетов, реальные фиксированные коллайдеры и сохраняются кадры Phaser. Ожидается выполнение на текущем source.
