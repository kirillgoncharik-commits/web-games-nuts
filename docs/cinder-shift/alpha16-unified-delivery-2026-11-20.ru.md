# Alpha.16: общая поставка и продолжение бэклога

Игровая база: f72e0117589dc9046e597fb9110a62130f3ae4c1 (арт alpha.15). Добавлены проверенные адаптеры из 8b80e720645e42f05f100cb56b5a41e660f82096 и звуковой профиль опубликованной Playgama alpha.12 из 04da23f0c34ff8c5fddf3fc6d1cdd1fe33b7303b. Чистый source SHA и идентификаторы новых пакетов фиксируются после сборки.

## Выполнено в этой итерации

- Бэклог 08/13: личные рекорды и резервные копии работают поверх гостевого транспорта Яндекса и Bridge; сохранена защита ошибок записи отдельно для каждого ключа.
- Исправлена блокировка очереди после синхронной ошибки чтения: Web Locks получает асинхронный callback. 14 контрактных проверок и 28 моделей транспорта/legacy/врагов/анимации проходят.
- Бэклог 05: портовый декор получает малое пиксельное движение, сохраняет неподвижность при паузе/reduced motion и не меняет коллайдеры.
- Интро сохраняет ожидающий переход при занятом сохранении, скрытой вкладке и смене ориентации. Добавлена проверка запуска при отказавшем Bridge checkpoint.
- Сборка Playgama выбирает только Bridge v2 и записанные аудиофайлы. Точные MIT-экспорты прежней опубликованной поставки сохранены с хэшами и лицензией для воспроизводимой сборки без внешней сети. Это не закрывает авторский музыкальный brief 09.
