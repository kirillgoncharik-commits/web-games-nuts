## Реализовано

- Только target Playgama загружает Bridge v2 stable; отдельный config рядом с index.html. Внешняя аналитика отсутствует, autoShow и дополнительные рекламные форматы выключены. Interstitial вызывается только на пользовательском переходе с результата после tutorial.
- Bridge initialize, game_ready, gameplay_started/stopped, начальные isPaused/isAudioEnabled и последующие события. Мут площадки не снимается игровым переключателем звука; ручная пауза не снимается host resume.
- Прогресс, настройки, активный мир и достижения используют один версионированный JSON-envelope через Bridge storage get/set. Прямые записи в localStorage/IndexedDB на этом канале отключены. Записи сериализованы, неизвестные/повреждённые данные не заменяются, cloud save не заявляется.
- Стартовый язык берётся из Bridge; английский — fallback. Ручной выбор действует в сессии, при следующем старте снова применяется Bridge language.
- CI проверяет приложение с контролируемым Bridge, запрещёнными прямыми storage API и повторной загрузкой; дополнительно проверяет Yandex и SDK-free itch. До фактического результата проверки остаются PENDING.

## Блокеры

1. **Аудио**. Текущие исходные эффекты и процедурная Web Audio музыка — не принятые площадкой аудиоматериалы. Перекодирование тех же синтезированных звуков не устраняет этот блокер. Нужен заменяющий набор записанных/произведённых в аудиоредакторе звуков и музыки в OGG/MP3. Не отправлять на модерацию с ложной отметкой соответствия.
2. **Реальный host QA**. Браузер/рабочая среда стали недоступны при продолжении. Нет подтверждённого запуска этого нового ZIP на Playgama, реального рекламного fill, гостевого/устройственного и независимого полного плейтеста.
3. Медиакарточка сохранена ранее, но загрузка игрового архива и проверка через кабинет ещё впереди. Обновлённый общий Release Pack со статусом Яндекса сохранён до этой отдельной интеграции; Playgama ZIP туда пока не добавлен.
