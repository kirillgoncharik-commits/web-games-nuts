## Задание
Реализовать PS-01–08 по спецификации и полностью довести новый development alpha до проверенной сборки и обновления ранее согласованных платформ, без выдуманной приёмки/публикации. Следующий свободный SemVer alpha согласно versioning-policy; 0.8.0-alpha.17 — предложенный номер. Одна runtime ревизия для всех профилей, отдельный docs HEAD допустим. Не перезапускать/откатывать текущую alpha.16 в процессе. Не делать scope creep в art/physics/SDK, кроме требуемых новой механикой и исправления блокирующих регрессий.

## Этап A — baseline и дизайн (до реализации)
- Зафиксировать HEAD, release_id, runtime tree SHA, deployed SHA/host/version per platform, открытые PR и known issues. Снять существующий baseline route/pressure/scoring/records; сравнить с отчётом bd102b8 и PR #24. Актуальный report может отличаться. Разобрать C01 M5G, C03 YU03-B/C, Cargo E/F и Firefox radio/audio по их реальному текущему статусу; не считать старый failure автоматически существующим. 
- Экспортировать topology report 84 rooms: room IDs, geometry/solids, routes, required objectives and enemies, optional nodes, state transitions, checkpoint hazards, station candidates, stock reachability; из session/missions.ts, room-data.ts, world-rooms.ts, world runtime/registry. Построить mission route graph, отдельно Foundry service/press, Cargo E01/Relay/power и возврат, Archive carrier/scout/upload, Reactor cooling/isolation/Regulator/evacuation, SW/YU mechanics and radio facts. Зафиксировать baseline snapshots/fixtures; обязательный output: topology-audit.json + readable diff/report.
- Снять wall-clock-free active simulation ms по сегментам, реальные volley counts (normal/W4 отдельно), damage/deaths, branch, wait/hold time, optional detours. Не использовать debug teleport/time skip. Использовать существующие campaign route harness/tests и реальные input paths; воспроизводимый seed, build, assist, loadout, input device.
- Рассчитать C/drain/station amounts по PS-06 на каждом маршруте после новой топологии; приложить machine-readable balance matrix и readable отчёт с таблицей all 15 × 3 difficulties, source and assumptions. Все расчётные стартовые значения из JSON provisional, не финальный acceptance.

## Этап B — модели, интеграция, UI
- Выделить чистую pressure state/model (EU, capacity, life budget, charges, checkpoint, transaction ids, cause), добавить typed config по mission/difficulty/mode. В mission.ts интегрировать MissionAttempt и snapshots: capture перед началом gameplay на каждом входе (после committed previous room), restore входной стороны, flags, local/global state, boss, seeded events/ledgers, sim time, station groups; не откатывать lifetime/attempt stats и consumed D4. Смерть и повтор разделены от terminal mission result; один idempotent transaction, game over только на нуле. Не перезапускать briefing/ad для room death.
- В room-scene.ts фиксированный sim step расход, фактически созданные volley/W4, pause/transition/ads/hidden guards, порядок simultaneous events, station interaction, collision/death/scene restart. В session/campaign.ts, world-progress.ts, world runtime, application.ts, score/clock/records, save/host-storage интегрировать room retry, no duplicate rewards or costs, difficulty persist, Continue/legacy semantics. Проверить все пути damage/ability/autoFire/repair/relay and platform lifecycle. Сохранить stable IDs и сохранения; migration/compatibility tests, не подменять SDK storage локальным.
- Добавить station entity/data/art/animation/SFX с готовым/depleted state и charge-group; переработать rooms согласно audit, route alternatives, обязательные gates, optional enemy IDs; не обходить сюжетные контакты. Доказать реальную достижимость и safety, не только расчёт геометрии. 
- В difficulty.ts, profile/research, challenge-spec/run-clock/score-ledger/challenge records/daily/duel/relay/time-attack-medals и UI внедрить profile PS-07; новые IDs/version/hash, legacy separation, ghost/split semantics, reproducible seeded modes. Существующие 5 modes прежде расширения списка миссий. Обновить i18n всех поддерживаемых локалей/RTL, HUD, death/retry/game over, result, tutorial, settings/briefing/What's New; reduced motion/flashes/mobile/accessibility, consented aggregate telemetry.
 
## Этап C — тесты и баланс
- Model/unit: deterministic drain, fractional EU/frame rate, no drain when paused/ads/hidden/transition/modal, zero threshold, actual shot and W1/W4, no double death on same tick, no invalid shot or negative values, station cap/charge group/backtracking, input hold/cancel, retry snapshot and idempotent rewards, optional routes, energy versus HP/D4, full mission restart, legacy migration and failures. 
- Integration: обычный keyboard/touch input, room retry all directions, persistent objectives/boss/quest items, branch switching constraints, score/analytics monotonic, no farming or double purchases, hidden/resume/orientation, all five modes (legacy codes/ghosts/records isolation), fresh unlock and existing profiles (including alpha.12/14/16), SDK per-key save failure/recovery, ads only final mission boundary. Доказательства: видео/кадры ключевых комнат + HUD normal/reduced/mobile; сравнить geometry/colliders, нет regressions.
- Route matrix: все 3 кампании × 3 сложности, целиком на exact source, один общий seed плюс минимум 2 альтернативных seed для событий/веток и отдельные tests service/press, Cargo E/F, Scout/no Scout, Cooling/Isolation, all station groups/optional branches. Stock Mira + representative upgrades, combat assist separately, touch path. Для каждого этапа report active ms, shots, charge, clip, min EU, EU at entry/exit, deaths/retries, graph edge, completion/reason, profile. Отдельно измерить fast/normal/cautious/detour/wasteful paths и energy-only death. Проверить сегменты и критерии из PS-06, адаптировать параметры; не проходить ценой debug flags, заскриптованного bypass или изменения времени. Human data optional but mark HUMAN_BALANCE_PENDING if unavailable, no invented P50/P90. Не скрывать failed jobs; повтор на неизменном SHA отделять от нового SHA.
- Запустить npm ci, npm run check, npm run art:check, npm run test:platform, npm run build, npm test (или current equivalent workflows), Chromium/Firefox/WebKit и existing full route/records/native SDK/production-art/performance tests; реальные мобильные устройства при доступности, иначе отметить. Обновить GDD/roadmap/current-work-order/development plan/coverage/status/quality gate/save format/release notes/version metadata с фактическими статусами и ссылками, не помечать PASS пока нет evidence. Новые regression tests для Pressure & Survival. Результат: один clean source commit, all critical gates PASS, release notes, risk log; если gate FAIL/UNKNOWN, не раскатывать затронутый пакет, исправить и повторить.

## Definition of Done и итоговый отчёт
1) PS-01–08 implemented, 84-room audit and 15×3 measured budgets/segment proofs, 9 full routes and alternate paths, tests and no pressure-critical regression; no debug bypass. 2) Docs/records/version/manifest consistent. 3) Immutable archives with hashes per target; host deployment matrix (BUILT/UPLOADED/DRAFT/IN_REVIEW/PUBLISHED/VERIFIED/BLOCKED/FAILED distinctly), prior versions/rollback paths and any human/host blockers. 4) PR with code and evidence links, source SHA/build IDs, actual known issues and updated roadmap; human balance acceptance separately pending if not measured. 5) Final summary to Kirill: before/after metrics (per mission/campaign, death reasons, time, energy, charge, paths, mode coverage), actual URLs and status; state exactly what was not completed. No claims of a fully green RC on alpha.
