# Alpha.14 — кандидат переноса в Yandex integration

20 ноября 2026. Отдельная ветка на основе integration 5ae5248efb9ae4ed14c06459527bdf9ec90213b8 и продуктовой 82c49240ae5080c334928afe63e0074ca23d33f0.

Ветка сохраняет SDK bootstrap, ready/gameplay lifecycle, host/ad pause и правила межстраничной рекламы из существующей интеграции. Поверх них перенесены радио YU05, read/merge/write статистики через выбранный HostRecordStorage, личные рекорды, счётчики и резервная копия. Settings в SDK-режиме не обращаются к отдельному локальному зеркалу языка. Пауза хоста останавливает обе категории времени. Общий web/itch путь сохраняет IndexedDB.

Новый workflow проверяет исходник head PR с контролируемым SDK: существующие три сценария жизненного цикла плюс реальные выстрелы/перезагрузка профиля, остановка часов и отказ/повтор записи. Отчёт manifest и результаты сохраняются как артефакт. Native product матрица остаётся отдельным gate. На момент подготовки результат этих новых проверок ещё ожидается.

Существующая release/integration ветка, отдельная Playgama ветка и live alpha.12 не перезаписываются. Это review-кандидат, без публикации в кабинет. Реальный SDK preview, upgrade/rollback опубликованных runtime, физические устройства и общий RC остаются открытыми. Playgama требует отдельного переноса его Bridge/bootstrap и запрета native storage; Yandex-кандидат не подменяет эту работу.
