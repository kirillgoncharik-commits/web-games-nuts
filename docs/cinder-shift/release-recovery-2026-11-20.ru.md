## Первая задача: C02 / SW03-B

Неудачный прогон: [44684590403](https://github.com/kirillgoncharik-commits/web-games-nuts/actions/runs/44684590403),
job `136115909445`, исходник Playgama `9cd11cb595f7484293ff5654519f334d046e4578`.

Из журнала: целевая точка `{x:248,y:320}`; фактический центр игрока
`{x:242.5,y:250,vx:0,vy:0}`. Ноги находятся на y=272, разница до пола — 48 px.
Фиксированная полка занимает x=212..236, y=272..320.
При ширине тела 22 px игрок с центром x=242.5 всё ещё перекрывает её край.

В `tests/final-world-routes.spec.ts` функция `walk()` допускает отклонение
до 7 px после остановки. `standAtHeight()` выполняет только одну попытку
спуска и затем утверждает нужную высоту. Это объясняет зафиксированную остановку
рядом с целевой точкой на верхней опоре и указывает на контроллер маршрута.
Вывод пока является диагностической гипотезой: повторный прогон и исправление
ещё не выполнены; дефект runtime этим не исключён.

Следующая проверка: точное достижение безопасной точки спуска и нужной высоты
обычным вводом. Сохранить строгую проверку высоты <2 px; затем пройти все
20 комнат / 5 миссий C02 и регрессию C03. Зелёный результат старого исходника
не закрывает последний неудачный результат Playgama.

## Порядок продолжения

1. Закрыть и подтвердить C02; канальную правку вернуть в соответствующий PR/интеграцию.
2. Завершить обязательные поля и видео Яндекса, затем оставшийся host QA.
3. Заменить аудио Playgama, загрузить проверенный target ZIP и пройти реальный QA.
4. Продолжить CrazyGames после независимого плейтеста; GamePix/Y8 после входа.

Блокер одного кабинета не задерживает доступную работу для остальных.
Существующие карточки обновлять по сохранённым ID. Не выдавать гостевой smoke
за независимый человеческий плейтест и не объявлять SDK CI проверкой реального хоста.
