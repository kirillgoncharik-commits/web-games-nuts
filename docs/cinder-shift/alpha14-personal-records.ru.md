# Alpha.14 — личные рекорды

20 ноября 2026. Продуктовый блок 13, поверх радиостанции из PR #15.

## Реализовано

- Главное меню → «Личные рекорды» → сводка / кампании / испытания. Назад возвращает в сводку и затем на прежнюю кнопку меню. Есть небольшой экран и стандартная навигация Panels.
- Созданные снаряды считаются в Projectiles.fire после проверки пула, первое принятое попадание — в фактическом месте урона. Пробитие и повторный callback не удваивают попадание; броня без урона, вражеский огонь и бросок не учитываются.
- Время идёт от интерактивного меню только в видимом сфокусированном экземпляре. Активные миссии — отдельное подмножество. Загрузка, countdown, ручная/платформенная пауза и сон останавливают интервалы. Исходные целые суммы дают точность с одним знаком.
- Новый отдельный personal-records.v1 сохраняет накопительные фрагменты сессий. Контрольная точка — каждые 15 секунд активного времени, а также результат, фон/закрытие и открытие профиля. Записи не выполняются на каждую пулю.
- Для IndexedDB read/merge/write и полная резервная копия выполняются одной транзакцией. Повтор/устаревший фрагмент не уменьшает итог и не удаляет другую вкладку. Повреждённая известная версия восстанавливается из целой копии с сохранением исходника в quarantine; будущая версия защищена от записи. Ошибка записи оставляет временные значения и возможность повтора.
- Прочитаны старые career и records.v1 / challenges.v1 / relay.v1. Подтверждённый флаг мира показывается отдельно от известной истории. Новые завершения трёх миров имеют стабильный campaign ID; Replay получает новый ID. Неполная история не создаёт ложный лучший результат.
- Сравнение группирует кампании по правилам/версии/помощи, испытания — по существующему ключу. До 20 последних попыток на испытание остаются в прежнем хранилище. Противник по коду и командный итог подписаны отдельно; собственные новые этапы Relay сохраняются раздельными ключами A/B.
- EN/RU — 964 ключа; встроенная история дополнена alpha.14.

## Доказательства до отключения рабочего компьютера

На локальном исходнике f4e5e7001346b3f21e1e49208b72a131b5356c4f, clean build local.20261120T063122042Z: 60/60 проверок в Chromium, Firefox и WebKit, 2.5 минуты. Включены контроль 10/4/40.0%, 39/25 секунд; реальная стрельба и reload; старая запись PB; будущая/повреждённая схема; резервная копия; два таба; отказ и повтор записи; закрытие после автоматической контрольной точки; обе версии радио reload и финал без потери HP.

На том же локальном runtime оба полных мира и два девятикомнатных маршрута Cargo с Retry прошли: 4/4, 10.2 минуты. Сборка, типы, EN/RU и арт-контракты проходили локально. Более поздние исправления перекрытой анимации YU05 и допуска выбора позиции C02 имеют отдельный исходник b8c712fb1df1c7d8a325439a069ef3f491b440a9; его полный повтор не завершён из-за отключения компьютера.

Этот PR переносит подготовленные исходные изменения через API GitHub поверх текущей радио-ветки; новый source SHA должен получить собственный exact-head CI. Предыдущие локальные проверки не подменяют этот gate.

## Что остаётся открытым

- Реальная последовательность upgrade/rollback на опубликованных web/itch и SDK preview; подготовлены локальные копии прежних runtime и захваченные старые профили, но полный upgrade-тест ещё не закрыт.
- Нативные транспорты Яндекса/Playgama и остальных каналов: новое атомарное обновление профиля надо адаптировать к соответствующему RecordStorage при переносе в integration, проверить quota, SDK/ad pause и повторные callbacks. Этот продуктовый source использует IndexedDB; отдельные SDK-ветки сохраняются.
- Полная матрица пяти испытаний и новых миссий; реальное прохождение/Replay всех трёх миров, разные условия помощи, счёт/время и полнота старой истории.
- Физические устройства, RTL и все 50 локалей. Это не сертификат общего RC.

Блоки 04–12 остаются в прежнем объёме. Публикации nuts.bid и itch alpha.12, отдельный C01 experiment и кабинеты платформ этим PR не обновляются.

Дополнительное уточнение часов: фиксированные переходы между комнатами и ожидание результата без доступной панели исключены из общего времени. Обычные меню и видимый результат учитываются. Отдельная модель проверяет эти границы; переполнение суммарных целых счётчиков отклоняется как повреждённая запись.
