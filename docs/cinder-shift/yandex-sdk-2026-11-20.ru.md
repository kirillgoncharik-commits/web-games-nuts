# Yandex SDK — интеграция 20 ноября 2026

Исходная игровая база: `836a04fbc8dc1cdb0d8dbbcba1ec0fc5b64034a5`. Игровые карты, баланс и ранее опубликованный itch ZIP в этой итерации не изменяются.

Добавлены подключение `/sdk.js` только в Yandex HTML, `YaGames.init()`, Game Ready после готовности меню, Gameplay start/stop по реальному состоянию, pause/resume SDK и остановка звука. Ручная пауза не снимается чужим resume. Старт и обратный отсчёт заблокированы во время host pause.

Сохранения Yandex используют `getStorage()` и атомарный гостевой JSON-envelope с прежними валидаторами кампаний. Неизвестная версия envelope, ошибка чтения и превышение квоты не заменяют прежние данные. Облачные сохранения не заявляются. Язык берётся из SDK; осознанный сохранённый выбор игрока сохраняется.

Interstitial допускается по пользовательскому переходу с результата после Airlock. Первый урок и соревновательные режимы исключены. Повторные callbacks и запросы одного transition ID не выполняют переход повторно. До открытия есть тайм-аут отсутствующего callback, после открытия ожидание реального close/error. Отдельные причины SDK/ad pause складываются.

Английский черновик 655191: иконка, обложка, горизонтальное видео скопированы из RU; добавлены 2 EN-скриншота, Save подтверждён. Тексты EN/RU сохранены. Обработка видео завершилась, но встроенный плеер сообщает Unable to play media; воспроизведение не подтверждено.
