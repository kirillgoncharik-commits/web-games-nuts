CINDER SHIFT 64 — ЗАДАНИЕ НА АРТ ДВУХ КАМПАНИЙ
Версия 1.0 · 08.11.2026 · производство и интеграция до релиза

1. ЦЕЛЬ
Два мира узнаются по одному кадру, остаются одной игрой и дают различимые игровые ситуации на протяжении 20–25 минут каждый.
Приоритет: читаемый игровой слой, образ Миры и понятные состояния механизмов. Арт должен работать в настоящем кадре игры, особенно на телефоне.
Источник намерения: созданные Figma concept board 2:2 / 2:137. Это mood/composition ориентиры, не готовые игровые background textures.

2. STYLE LOCK ПЕРЕД МАССОВЫМ ПРОИЗВОДСТВОМ
Снять из актуального билда: базовый pixel scale, размер героя H, tile grid, viewport (существующий layout ориентируется на 640×360), materials, outlines, palette, anchors/atlas conventions.
Не менять коллизии/размер Миры ради иллюстрации малого масштаба. Масштаб мира достигается увеличенными предметами относительно H.
Сделать по одному style key на мир: фон + игровой слой + Мира + один интерактивный объект во всех основных состояниях.
Проверить 1×/2× и фактический mobile viewport; зафиксировать palette/light/value hierarchy и повторяемые материалы.
После production checkpoint продолжать согласованный вариант; не ждать общей неопределённой «приёмки всего арта», оставляя runtime пустым.

Общие правила:
— узнаваемый существующий костюм, согласованный силуэт/пропорции; игровой спрайт, портрет и promo не обещают разных героев;
— чёткий масштаб пикселя, без случайного смешения pixel art и размытого реализма;
— фон спокойнее игрового слоя; границы платформ, коллизий, опасностей и exit читаются;
— свет/цвет не заменяют форму/движение состояния; «уязвим» видно по открытой панели/силуэту;
— декор не выглядит как непроходимая платформа или доступный выход;
— foreground не скрывает героя/telegraph: cutout/ослабление по принятому renderer contract;
— обязательный текст/инструкции не запечены в картинке; UI labels локализуются живым текстом;
— не делать новые кадры Миры ради общего косметического апгрейда. Делать необходимые carry/pickup/throw состояния из текущего рига/overlay.

3. МИР 1 — «МАЛЕНЬКАЯ СМЕНА»
Палитра: #182D35 / #F4BD62 / #72D4BE / #E77762.
Ощущение: обычный тёплый дом становится большим приключением. Материалы узнаваемы — керамика, дерево, ткань, пластик, металл, листья.
Цель масштаба: герой примерно с бурундука; кухонная столешница/ножки/полки задают высоту, кружка и прищепка сопоставимы с героем/больше деталей, но сохраняют осмысленные пропорции.
«Чип и Дейл» — только ощущение масштаба/использование предметов. Персонажи, позы, сцены, музыка и айдентика принадлежат Cinder Shift.

Пять самостоятельных арт-секторов:
SW01 Kitchen: столешница, кружка, сушилка/тарелки, ручки ящика, хлебница, док пылесоса.
SW02 Desk: клавиатура, кабели/катушки, бумажный лоток, книги/канцелярия, принтер, лампа.
SW03 Laundry: корзина, тканевые складки, стойка/прищепки, ремешки, внешний воздушный канал, заслонка.
SW04 Balcony: терракота, листья, полотенце, флажок ветра, жёлоб/вода, флюгер.
SW05 Router shelf: полки/книги, кабельные крепления, корпус роутера/плата, проводник, три части маяка, фазовая установка.

Для каждого сектора: три фоновых плана, свой foreground/platform dressing, шесть ключевых читаемых пропсов и узнаваемый landmark.
Повторно использовать общие материалы/детали можно, но не выдавать перекраску одной комнаты за пять локаций.
Обязательные интерактивные состояния:
крышка/катушка — available, held, thrown, landed, spent/returned;
контакт — inactive, actionable, activated/locked;
сканер/док — idle, warning/scan, active, exposed, disabled;
маяк — missing pieces, ready, charging, complete.
Пар/ветер/вода: спокойная фаза, предвестник, активная зона, спад; мягкие частицы не перекрывают опасность.
Carry overlay Миры: idle, walk, jump/fall, pickup, throw, drop; hand/held object/throw origin anchors и нужные silhouettes для left/right.
Поворот/бросок не отрывает руки от предмета; оружие не стреляет из занятой позы.

4. МИР 2 — «АДРИАТИЧЕСКИЙ СИГНАЛ»
Палитра: #233842 / #E9A06C / #70A6A8 / #D76553.
Ощущение: вымышленный адриатический город летом 1986. Тёплая повседневность, море/камень, послевоенный модернизм и аналоговая техника.
Не превращать всё в серый военный bunker или набор универсальных «советских» штампов. Сохранить человеческий масштаб: окна, шторы, бельё, бумажные объявления, вечерний свет.
Документировать датировку крупных узнаваемых предметов. Футуристическое — только костюм/аномальные механизмы, явно отделённые от нормального мира.

Пять арт-секторов:
YU01 Telecom: двор жилого блока, вход/лестница, телефонный шкаф/коммутатор, аналоговый аппарат, крыша/антенны, бельевые тросы.
YU02 Harbour: складские ворота, контейнеры, кран/грузовая площадка, причальные тумбы, рабочее освещение, портовый передатчик.
YU03 Rail: перрон, бумажное расписание, служебный электропоезд, дверные узлы, тоннельные ниши, подстанция.
YU04 Factory: станок/привод, конвейер, безопасные мостки, распределитель, защитный экран, машинный зал.
YU05 Radio hill: склон/залив, техническая галерея, ретрансляторы, антенный узел, CRT/rack оборудования, аномальный разлом.

На каждый сектор: три фоновых плана, platform/foreground dressing, шесть ведущих пропсов и landmark.
A/B контуры имеют повторяемую форму проводки/ламп и отдельные state silhouettes, не только красный/зелёный.
Рубильник: A, switching, B, locked/disabled; физическое положение ясно и без знания языка.
Мост/дверь/щит: off/safe, warning/moving, on/settled, obstruction-safe.
Передатчик: offline, line_ready, transmitting, restored; карта отражает результат.
Сервисный аномальный механизм: idle, telegraph, active attack, exposed, disabled. Обычные люди/животные не становятся врагами.
Латиница/кириллица в среде допустимы как аутентичный декор; обязательный смысл игроку даёт локализуемый UI. Не генерировать нечитаемые псевдобуквы в крупных вывесках.

5. МИНИМАЛЬНЫЙ АРТ-КОМПЛЕКТ
— 2 campaign cover composition и 2 result/ending composition.
— 10 scene background sets по 3 планам; 2 coherent platform/material kits с вариациями всех секторов.
— 60 ключевых prop assets (6 на сектор), допускаются разумные shared components.
— 10 mission/map illustrations в одной системе. Cover/briefing могут использовать согласованные crop существующих источников.
— 12 наборов shared interactive mechanisms (по 6 на мир), со всеми состояниями; уникальные props могут ссылаться на них.
— 6 carry/action overlay states для Миры.
— 2 campaign UI icon sets + 2 coherent VFX packages.
Это логические assets, а не фиксированное число PNG/кадров. production/art_asset_manifest.csv — начальная ведомость; расширять, если runtime содержит новый объект/состояние.
Ни одно обязательное состояние не остаётся прямоугольником/нейтральной заглушкой. Недостающий sprite не скрывать fallback-кадром.

6. ИСХОДНИКИ И RUNTIME
Редактируемые layered sources в принятом pipeline (Aseprite/PSD/SVG/существующий rig); PNG/atlas exports и metadata для движка. Не вводить Spine только ради нового формата.
Атлас: прозрачность, padding/extrusion, без обрезанных частей/плавающих pivots. Реальные размеры/texture limits фиксируются по проекту и portal budget.
Для каждого asset: stable ID, campaign/sector, source, runtime atlas/frame, logical size, pivot/anchors, state list, rights/provenance, used rooms, status.
Сохранить проверки существующих 34 кадров/anchors и расширить contract для новых состояний. Правило «ровно 34» не должно запрещать новый контент.
Все экспортные команды воспроизводимы; без ручной неизвестной подмены файлов в dist.
Large backgrounds/music не предзагружаются все вместе ради выбора кампании; загружается нужный сектор/мир с соблюдением target budgets.

7. ПРИЁМКА АРТА
Contact sheet 1×/2×/mobile scale, in-game shots всех 10 миссий и всех interactive states, manifest coverage.
Миру/платформы/вражескую угрозу видно на маленьком экране; форма уязвимости/маршрута понятна без цвета.
Два мира и пять секторов каждого различимы без текстовой подписи.
Нет пропущенных ссылок, случайного blur, incompatible pixel scale, clipping, исчезновения held item, псевдотекста и копий чужих героев.
Исходники/экспорты совпадают с подключённым runtime. Все 40 комнат пройдены, а не проверены только на загрузку стартового экрана.
