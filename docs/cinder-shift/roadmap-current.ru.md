# Cinder Shift 64 — актуальный порядок этапов

Обновлено 7 ноября 2026 по единому пакету беты 1.0. [Gap-list](unified-beta-gap-list.ru.md) содержит начальный SHA, фактическую production-версию и разрывы. Редакция 1.0 задаёт полный объём Beta; M05B.1–.3 ниже — внутренние этапы, не отдельные выпуски.

| Этап | Состояние |
| --- | --- |
| M0–M03 | Основа, управление, первая миссия и графика вошли в M05A |
| M04 | Исследования, E02/E03, сохранение, EN/RU и единый UI вошли в M05A |
| M05A | Опубликована 0.5.0-m05a.1, артефакт b450c6e; [отчёт](m05a-status.ru.md) |
| M05A.1 | Опубликована 0.5.1-m05a.1; [статус и проверки](m05a1-status.ru.md). Ручная приёмка открыта |
| M05B.1 | Локальный черновик: 0.6.0-m05b1.3, две миссии / 7 комнат / 6 технологий / 3 события; [рабочий статус](m05b1-status.ru.md). Не опубликована и не принята |
| M05B.2 | Будущий объём: Литейная и Архив; итого 4 миссии / 15 комнат / 9 технологий / 5 событий |
| M05B.3 | Будущий объём: Реактор, Регулятор и итог; 5 миссий / 20 комнат / 12 технологий / 6 событий |
| M06 | Баланс, доступность, дерево и активный слот, полировка |
| M07 | Полная приёмка устройств и опубликованного артефакта |
| M08 | Канальные сборки и подачи на площадки |

Цель первого выпуска — 20–30 минут активного прохождения, ориентир 25. Человеческая длительность пока не измерена. Ручная приёмка M05A остаётся открытой; дальнейшее производство кампании зависит от понятного боя и повтора.

Для первого выпуска сохраняется Retry текущей миссии с входной сборкой, тем же планом событий и полным допустимым HP. Сброс кампании при смерти не введён. Дополнительные герои и сюжет на 60–90 минут остаются последующим объёмом.
