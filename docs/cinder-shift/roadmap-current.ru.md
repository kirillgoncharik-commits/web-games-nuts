# Cinder Shift — актуальный порядок этапов

Обновлено по заданию M03 от 5 ноября 2026. Старые задания остаются историческими документами; следующая нумерация заменяет прежнюю очередь.

| Этап | Объём | Состояние |
| --- | --- | --- |
| M0–M1 | Основа и управление | Основа выпущена; проверка реальных устройств продолжается |
| M02 | Первая миссия A–B–C, бой и результат | Реализована локально; публикация, длительность и ручная приёмка открыты |
| M03 | Растровая графика и UI при неизменной симуляции | Внедрена локально; финальная приёмка и публикация открыты |
| M04 | Вертикальная сессия: три первых технологии, два события, сохранение и продолжение | Следующий игровой этап; пока не реализован |
| M05 | Полная кампания | Будущий объём |
| M06 | Полировка выпуска | Будущий объём |
| M07 | Итоговая проверка | Будущий объём |
| M08 | Публикации на площадках | Будущий объём |

Релизная цель успешного прохождения — 20–30 минут, ориентир 25; измерять без пауз и повторов. После релиза пользователь планирует сюжетные уровни до 60–90 минут общего прохождения. Рабочее предложение — три главы с отдельными забегами по 20–30 минут, сохранением открытых глав и сбросом текущего забега при смерти. Это направление для проектирования M04 и дополнений, а не существующая система M02/M03. Длительность не набирать ростом HP и обязательными повторами.
