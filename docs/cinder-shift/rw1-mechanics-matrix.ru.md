# M-RW1 · матрица технологий и событий

Это инженерные доказательства, а не полная игровая приёмка. Входные fixture-состояния задаются один раз до эпизода; дальше тесты используют клавиатуру/реальный touch. Полный проход кампании запускается с нового профиля без fixture и покупок.

| ID | Действие и ограничение | Проверка | Что остаётся |
| --- | --- | --- | --- |
| W1 | Три направления выстрела; это отдельные пули | Полный Airlock W1, оружейная сборка Регулятора; модель ограничения урона за окно | Человеческое сравнение стрельбы по группе |
| W2 | Одна помеченная тонкая панель на пулю; обычная геометрия блокирует | Модель второй панели; настоящий прострел e-sheet в Cargo с W2 | Сопоставление на всех типах врагов |
| W3 | Одно отражение от помеченной поверхности | Настоящая пуля у m4g-ricochet меняет вертикальное направление, расходует отражение и сохраняет hit ID | Разметка отражённого попадания по ядру босса |
| W4 | Заряженный выстрел только в выбранном слоте W4; отдельный cooldown | Полный бой W1–W4; отдельный выстрел наносит 4 урона, ранний повтор отвергается, следующий работает после cooldown | Человеческая оценка сигнала |
| M1 | Наземный рывок, если выбран M1 | Airlock M1, проверки ввода и фиксированной дистанции | Оценка удобства на физическом устройстве |
| M2 | Воздушный рывок с активным M1 | Настоящий прыжок + K в Cargo, скорость выше обычной | Естественное применение новым игроком |
| M3 | Рывок сквозь помеченную стену | Сравнение M2/M3 в одной Archive M4F; стена остаётся в solids | Читаемость метки стены |
| M4 | Рывок сквозь фазовый барьер | Сравнение M3/M4 в одной Reactor M5A | Читаемость различия wall/phase |
| D1 | Максимум HP 6 → 8 | Четыре плана Airlock, Retry/reload, сохранение покупки | Сравнение общей кривой сложности |
| D2 | Один буфер на комнату; общая неуязвимость после попадания | Настоящий удар, HP 8 → 8, бирюзовый кадр; сброс на Retry | Первое понимание игроком |
| D3 | После поглощения очищает текущие вражеские пули | Сравнение D2/D3 под настоящей очередью турели: D3 удаляет остальные летящие пули; исправлено их восстановление после callback | Человеческая оценка сигнала и полезности |
| D4 | Один раз предотвращает смерть, восстанавливает 2 HP | Настоящий контакт после D2: 1 → 2 HP, затем следующая смертельная серия завершает попытку; одно событие спасения | Человеческая оценка сигнала и пользы |

| Событие | Место и действие | Проверка |
| --- | --- | --- |
| E01 v2 | Cargo F: восстановление питания меняет заслонку/турель | Cargo со включённым/отсутствующим E01, W2/M2/D2; full-HP Retry |
| E02 v1 | Airlock B: верхняя заслонка | Все четыре исходных seeded-плана, проход с новой связью B → M1A |
| E03 v2 | Airlock B: ремонт или salvage | Выбор один раз; ремонт ограничен максимумом; повтор/Reload не дублируют награду |
| E04 v1 | Foundry M3C: heat-cycle | Модель и отдельные вводимые случаи E04 on/off: настоящий активный нагрев, предупреждающий звук и безопасное пересечение. Seed 4 полного press-прогона не содержит E04 |
| E05 v1 | Archive M4B: Scout/HP; без события salvage | Три полных базовых маршрута; Scout убирает физический экран и удлиняет предупреждение |
| E06 v1 | Reactor M5B: необязательный таран | Оба контура с принятием/отказом; появление вне solids, запас для отхода, полное предупреждение, награда за уничтожение |

Для закрытия RW-03.01 остаётся полная проверка визуального/звукового подтверждения и ограничений каждой технологии/события. Наличие всех трёх полных веток в тесте босса само по себе её не заменяет.
